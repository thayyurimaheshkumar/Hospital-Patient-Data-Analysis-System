# Hospital Patient Data Analysis System

## Project Description
A web-based application designed to analyze hospital patient visits, department workload, and patient statistics.

## Live Project Website
https://flawless-health-data-pulse.base44.app

## Features
- Patient details search
- Patient ID and patient name
- Department-wise analysis
- Patient statistics
- Interactive dashboard
- Data visualization

## Technologies Used
- HTML
- CSS
- JavaScript
- Base44
